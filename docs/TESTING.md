# Проверка ArtiCrystals 1.0.0+26.3 — набор из 16 минералов

Дата: 31 октября 2026 года.

## Сборка

Minecraft 26.3, Fabric Loader 0.19.5, Fabric API 0.163.0+26.3,
JDK 25.0.5, Loom 1.17.12, Gradle 9.6.0. Общая и клиентская части
скомпилированы, релизный JAR и sources JAR собраны. Тестовый мод в релиз
не включён. Публичный номер версии на CurseForge — 1.0.0.

## Серверные игровые тесты

Прошли **10 из 10**: 9 тестов ArtiCrystals и базовый тест Fabric.

- Все 16 рецептов синтеза дают правильный предмет с точным расходом.
- Неверные, отсутствующие и лишние ингредиенты отклоняются.
- Shift-клик повторяет синтез; полный инвентарь не расходует ингредиенты.
- Закрытие стола возвращает ингредиенты и не выдаёт незабранный результат.
- Все 16 кластеров крепятся на 6 сторон и поддерживают воду.
- Потеря опоры разрушает кластер с единственным выпадением.
- Все 58 обычных рецептов загружены.
- Все 112 звуковых событий зарегистрированы, блоки и кластеры используют
  звуковой набор своего минерала.
- Яркость всех минералов и четырёх ламп соответствует каталогу;
  кристальная подзорная труба включает и выключает режим приближения.

## Клиентский игровой тест

**Пройден** на Minecraft 26.3 с Fabric API 0.163.0+26.3.
Программный OpenGL, SDL offscreen, OpenAL null backend.

- Загрузились все 112 звуковых событий. Каждое разрешается в существующую
  ванильную запись OGG, а не в пустой звук. У всех 16 минералов различается
  итоговая высота звона при одинаковом случайном выборе записи.
- Создан одиночный мир, установлены блоки и кластеры всех 16 минералов.
- Открыт синтезатор с рецептом рубина; результат отображается.
- Справочник перелистан до лунного камня (16 / 16), проверен переход
  вперёд с последней страницы и назад с первой.
- Получены и просмотрены скриншоты мира, синтезатора и страницы лунного
  камня. Новые модели и текстуры отображаются.

Записи звуков берутся из Minecraft/активного ресурспака. Собственные новые
аудиозаписи не создавались: sounds.json задаёт отдельную высоту тона для
каждого минерала. Звук динамиками здесь не прослушивался; тест проверяет
загрузку записей и их параметры в клиенте.

## Статическая проверка ресурсов

58 моделей, 57 определений предметов, 58 обычных рецептов,
112 звуковых событий. Проверены ссылки, границы моделей, уникальность
геометрии и рисунков, переводы и субтитры RU/EN. У каждого из четырёх
добавленных минералов отдельная геометрия предмета и кластера.
`articrystals-models.png` — рендер моделей, не игровой скриншот.

## Границы проверки

Текущий набор из 16 минералов проверен с API 0.163.0+26.3. Более ранний
набор из 12 минералов также запускался на выделенном сервере с API
0.165.0+26.3; это не отдельный повторный тест текущей сборки.
Проверка всех сочетаний сторонних модов не проводилась.
Тестовая среда использует локальную поправку определения Unix-сокетов
в инструменте Loom, так как они здесь запрещены. В исходники проекта и
релизный JAR эта поправка не входит.

## Замена иконки — 1 ноября 2026

Иконка перерисована скриптом Pillow на сетке 32×32, увеличена без
сглаживания до 256×256 внутри JAR и 512×512 для CurseForge.
Все остальные записи JAR побайтово совпадают с проверенной сборкой
из 16 минералов; номер версии 1.0.0+26.3 сохранён.
Повторная генерация PNG даёт идентичные байты.
